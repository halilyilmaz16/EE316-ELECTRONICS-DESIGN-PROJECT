# ltspice

Simulation of the water level controller.

- `EE316_30.06.2026.asc`: LTspice schematic of the full circuit.
- `ee316.zip`: the same schematic with its ACS712 symbol and model (`ACS712_allpins.lib`, `ACS712_30A_allpins.asy`) and the simulation outputs. The raw file is about 33 MB, so it is kept zipped.

To rerun, extract the zip and open the `.asc` file in LTspice. Keep the ACS712 files next to it so the symbol and model are found.
